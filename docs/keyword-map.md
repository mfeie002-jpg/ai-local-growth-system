## Warum nicht mehr Landings

Die Cluster "digitalisierungscheck kmu", "business audit schweiz", "marketing automation kmu", "ai search visibility" haben in Semrush kein messbares Volumen im CH-Markt. Eine eigene SEO-Landing pro Cluster erzeugt dünne Doorway-Pages ohne Traffic-Erwartung. Diese Themen werden stattdessen in:

- `/insights` (Blog) als Content-Assets
- Homepage-Abschnitten als Positioning
- `/ueber-uns` als Methodik/Entity-Signal

behandelt.
